鈴鹿コース11 自動運転シミュレーター紹介サイト

このフォルダーは、添付されたFLEX SITEをベースにした静的な紹介ページです。
車やシミュレーターを実際に動かす機能は入れず、コース画像・走行動画の掲載枠・説明文・資料リンクを掲載しています。

使い方
1. フォルダー内の index.html をブラウザで開くと確認できます。
2. assets/course-11-mask.png を差し替えるとコース画像を変更できます。
3. index.html の video-placeholder 部分を <video controls> に変更すると、走行動画を掲載できます。
4. docs フォルダーには、元ツールのREADMEと制御仕様書を収録しています。
5. 問い合わせ先は index.html の mailto リンクを実際のアドレスへ変更してください。

主なファイル
- index.html       紹介ページ本文
- styles.css       デザインとレスポンシブ表示
- script.js        スマホメニューと年表示
- assets/          コース画像
- docs/            元ツールの資料
