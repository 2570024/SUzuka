HOW IT WORKS

入力を見て、
操作を返す。

シミュレーターの参加者が編集するのは、毎フレーム渡される観測情報から操作を返す制御ロジックです。

01

Observation

速度、位置、向き、次のチェックポイント、壁までの距離、路面、進捗などを受け取ります。

obs.rays['front']
02

Control

観測した情報を使い、ステアリング・アクセル・ブレーキの値を毎フレーム計算します。

control(obs) → Action
03

Evaluation

完走・タイム・衝突回数・平均速度・滑らかさ・エラー回数などで走行結果を確認します。

time / crashes / smooth

路面も観測対象。 road / ice / mud / boost の違いで、グリップ・加速・制動・抵抗が変わります。

03
